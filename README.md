# Fraud Detection ML

This project implements a machine learning pipeline to detect fraudulent credit card transactions.

Pipeline steps:
- Data cleaning and feature selection
- Encoding categorical variables
- Handling class imbalance
- Training a Random Forest classifier
- Threshold tuning to improve fraud recall
- SMOTE oversampling
- Evaluation using confusion matrix, precision, recall, and F1-score

Goal: maximize fraud detection recall while maintaining acceptable precision.
